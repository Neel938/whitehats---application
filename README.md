3. Recent Cybersecurity Incident: Stryker Wiper Attack
Medical technology company Stryker was reportedly hit by a destructive "wiper" attack in 2026. The Iran-aligned group Handala is said to have abused Microsoft Intune access to remotely wipe tens of thousands of devices. No ransom was demanded, so the goal was pure disruption, and it reportedly hurt the company's earnings.

What I learned: Device-management tools are powerful, so a single compromised admin account can become a way to attack an entire fleet. This is why strong MFA, least-privilege access and monitoring of admin actions matter.
